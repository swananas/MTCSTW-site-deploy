4 Adjust donor-data logic

One important difference: we return organization-level, geographic, and candidate-level aggregates — not individual donor records. Federal law (52 U.S.C. § 30111(a)(4)) prohibits commercial use of individual contributor identities. If your app displayed per-donor rows, refactor to aggregate views.

FAQ

Is this really free?

Yes — 1,000 API calls/month, no credit card. Paid tiers start at $69/month for 50K calls.

Where does the data come from?

Public sources: FEC filings, Senate lobbying disclosures (LDA), SEC EDGAR, USPTO, OSHA, EPA, and 40+ more. All aggregated, all sourced.

Why can't I get individual donor names?

Federal law prohibits it for commercial use. We enforce this at the data layer — the API physically cannot return individual contributor identities.
