Our take

🏆 Best overall: Propaganda Factory API

We're biased, obviously. But on the merits: it's the only live API purpose-built for money-in-politics plus corporate accountability data, with a free tier and self-serve signup. The AI connection layer (donation-to-contract timing, etc.) exists nowhere else.

📉 OpenSecrets: great data, dead API

OpenSecrets.org still has the best website for browsing money-in-politics data. But their API is gone and isn't coming back. If you need programmatic access, you need to look elsewhere. Migration guide →

💰 Bloomberg: powerful, priced for banks

If you're a hedge fund with $25K/seat to spend, Bloomberg's data is excellent. For journalists, researchers, activists, and indie developers, it's not a realistic option.

📰 ProPublica: great journalism, limited APIs

ProPublica's data tools (Nonprofit Explorer, etc.) are excellent and free. But they're individual tools, not a unified API — and they don't cover campaign finance or lobbying programmatically.

Which should you choose?

  • Building an app or dashboard? → Propaganda Factory API (only live option with a free tier)
  • One-off research? → OpenSecrets.org website (free, no API needed)
  • Nonprofit lookups? → ProPublica Nonprofit Explorer (free, specialized)
  • Institutional finance? → Bloomberg (if budget allows)
  • Migrating off OpenSecrets API? → Start here
